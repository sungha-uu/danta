# 수익률 구조 개선 포인트

- 문서 등급: 활성 성과 개선 기준
- 적용 범위: 백테스트, 모의투자, 모의 그림자, 소액 실전, 제한 실전
- 안전 우선순위: [`EXIT_AND_RISK.md`](EXIT_AND_RISK.md)의 `-7%` 강제 손절이 항상 우선

## 1. 목적

이 문서는 단기매매 전략의 순수익과 안정성을 함께 높이기 위해 검토할 항목, 실험 방법, 평가 지표와 승격 절차를 관리한다. 단기 수익률 한 번을 최적화하는 문서가 아니라 여러 시장 국면에서 비용 차감 후 양의 기대값을 유지하고 큰 손실과 수익 반납을 억제하는 구조를 만드는 문서다.

튼튼한 구조는 손실 확률과 운영 오류를 줄이고 성과의 재현 가능성을 높일 수 있지만 안정적 수익이나 원금 보장을 의미하지 않는다. 실계좌 승격은 충분한 표본, 미사용 데이터, 모의·실전 체결 차이와 위험 한도를 모두 통과해야 한다.

## 2. 절대 규칙과 개선 가능 영역

### 절대 규칙

- 평균 체결가 대비 `-7%` 도달 시 사용자 재확인 없이 매도 가능 수량 전부를 즉시 시장가 손절한다.
- 손절은 AI 판단, 익절, 박스 유지 예상, 사용량 부족이나 시스템 일반 킬스위치로 지연할 수 없다.
- 사용자 `ENTRY_MANDATE` 없는 매수, 물타기와 승인 범위 밖 추가매수는 금지한다.
- 실전 전략은 일일 성과에 따라 자동 변경하거나 자동 승격하지 않는다.

### 개선 가능 영역

- 후보 선별과 AI 등급의 정확도
- 진입 목표가, 하단 접근과 반등 확인 조건
- 주문 체결 방식, 미체결 취소와 슬리피지 억제
- 종목별 주문가능현금 배정률과 동시 보유 수
- 박스 무효화, 시장위험과 시간청산
- 수익관리 활성 시점, 상승 지속 점수와 수익보호선
- 거래 빈도, 재진입 제한과 현금 대기 조건

익절에는 고정된 불변 수익률을 두지 않는다. AI는 모의 결과를 바탕으로 개선안을 제안하고, 승인된 결정적 로컬 엔진이 장중 실행한다.

## 3. 수익성과 안정성의 공동 평가

모든 실험은 수수료, 세금, 예상 슬리피지와 미체결을 반영한 순성과로 비교한다.

| 관점 | 핵심 지표 |
| --- | --- |
| 수익성 | 거래당 순기대값, 누적 순수익률, 손익비, Profit Factor |
| 하방 위험 | 최대낙폭, 일·주·월 손실, 최악 거래, 하위 5% 손익 |
| 안정성 | 월별 양의 수익 비율, 수익 변동성, 연속손실 횟수·길이 |
| 청산 품질 | MFE·MAE, 최고수익 반납률, 청산 후 추가 상승·하락 |
| 실행 품질 | 주문 체결률, 체결 지연, 슬리피지, 부분체결·취소율 |
| 자본 효율 | 평균 투자비율, 현금 대기시간, 보유시간, 동시 포지션 |
| 후보 품질 | 등급별 반등률, 박스 유지율, 하단 진입 후 붕괴율 |

승률만 높거나 총수익만 큰 전략은 채택하지 않는다. 기대값이 양수여도 최대낙폭·연속손실·체결 실패가 허용 한도를 넘으면 안정판으로 승격하지 않는다.

## 4. 시장 국면별 분리 검증

전체 평균은 다음 국면별 결과를 가릴 수 있으므로 반드시 분리한다.

- KOSPI 상승·횡보·하락·급락
- 업종 강세·중립·약세
- 고변동·저변동
- 고유동성·유동성 감소
- 갭 상승·갭 하락
- 외국인·기관 동반 순유입, 엇갈림, 동반 순유출
- 장 초반·장중·장 후반 진입

특정 국면에서만 유효한 로직은 해당 국면 탐지 신뢰도가 검증된 경우에만 조건부 활성화한다.

## 5. 익절 로직 검토 포인트

### 보유 연장 근거

- 체결강도와 매수 주도 체결대금이 유지 또는 증가
- 거래량·거래대금 증가와 가격 전진이 동반
- 1분봉과 5분봉의 고점·저점이 함께 상승
- VWAP 위 유지와 박스 상단 돌파 후 안착
- 매도잔량 흡수와 매수호가 보강
- KOSPI와 업종 흐름이 포지션 방향을 지지

### 조기 청산 근거

- 박스 하단 또는 승인 당시 무효화 수준 이탈
- 수익 중 상단 돌파 실패와 윗꼬리 반복
- 거래대금은 크지만 가격이 전진하지 않는 흡수 실패
- 체결강도·순매수 체결대금 반전
- 1분봉 하락과 5분봉 둔화 동시 발생
- 시장·업종 급락, 시세 신선도 또는 주문 경로 이상
- 최대 보유시간 초과

### 반드시 비교할 청산 방식

- 고정 목표수익 청산
- 연속 점수 기반 적응형 청산
- ATR 기반 추적 보호선
- 박스 상단 거부 청산
- 시간청산
- 위 조건들의 조합

부분 익절은 현재 기본 범위에 포함하지 않는다. 필요성이 입증되면 별도 실험과 사용자 승인 후 추가한다.

## 6. 실험 방법

1. 기준판과 개선 가설을 한 문장으로 정의한다.
2. 한 실험에서는 가능한 한 핵심 변수 하나만 바꾼다.
3. 개발·검증·최종 미사용 구간을 시간순으로 분리한다.
4. 미래 데이터 누수 없이 워크포워드로 반복한다.
5. 기준판과 개선판에 동일한 종목군·기간·비용·체결 가정을 적용한다.
6. 전체와 시장 국면별 지표, 표본 수와 신뢰구간을 기록한다.
7. `PAPER_CHALLENGER`에서 모의 주문으로 체결 가능성을 확인한다.
8. `PAPER_SHADOW`에서 안정판과 같은 시각의 신호 차이를 대조한다.
9. 사용자 검토 전에는 `LIVE_CHAMPION`을 변경하지 않는다.

좋은 결과가 나올 때까지 기간·임계값을 반복 선택하는 과최적화를 금지한다. 여러 대안을 동시에 시험하면 실험 개수와 선택 편향을 기록한다.

## 7. AI 에이전트의 역할

AI 에이전트는 다음을 수행한다.

- 매 거래일 데이터·주문·성과 이상을 요약하되 전략을 자동 변경하지 않는다.
- 손실 거래와 수익 반납 거래를 원인 유형별로 분류한다.
- 후보 선별·진입·배정·청산 중 어느 단계가 성과를 훼손했는지 분해한다.
- 개선 가설, 기대 효과, 부작용, 필요한 표본과 중단 조건을 제안한다.
- 실험 결과를 기준판과 비교하고 유지·추가검증·폐기·승격 후보로 판정한다.
- 분석에 사용한 데이터 구간, 모델·프롬프트·전략 버전을 남긴다.

AI 에이전트는 장중 외부 LLM 응답으로 틱 단위 매도를 결정하거나, 모의 성과만으로 실전판을 자동 변경하지 않는다.

## 8. 운영 주기

### 매 거래일

- 거래별 MFE·MAE, 실제 청산 사유, 비용, 슬리피지와 최고수익 반납을 저장한다.
- 치명적 안전·데이터·체결 문제를 즉시 분리한다.
- 성과가 나쁘다는 이유만으로 당일 전략을 수정하지 않는다.

### 매주

- 손실·수익 반납·기회 누락의 반복 패턴을 검토한다.
- 개선 포인트의 우선순위와 최소 실험 표본을 정한다.
- 단순 결함 수정과 전략 변경을 구분한다.

### 매월

- 기준판과 개선판을 동일 조건으로 비교한다.
- 기대값, 최대낙폭, 연속손실, 국면별 일관성과 체결 품질을 종합 판정한다.
- 유지·추가검증·폐기·소액 실전 후보를 사용자와 결정한다.

### 분기 또는 중대 사건 발생 시

- 시장 구조, KIS 체결 차이, 데이터 공급과 비용 가정을 전면 재검토한다.
- 큰 낙폭, 손절 실패, 실전·모의 괴리가 발생하면 정기일을 기다리지 않는다.

## 10. 승격 조건

구체적인 수익·낙폭 임계값은 충분한 모의 기준선이 쌓인 뒤 사용자와 확정하며 그 전에는 `TBD`다. 최소한 다음 조건을 모두 만족해야 한다.

- 비용 차감 후 기대값이 기준판보다 개선됨
- 최대낙폭과 연속손실이 허용 범위 이내
- 특정 한 달이나 종목 몇 개에 성과가 집중되지 않음
- 상승·횡보·하락 중 검증 대상 국면에서 결과가 설명 가능함
- 미사용 평가와 모의 주문에서 재현됨
- 실전·모의 체결 차이와 롤백 계획이 확인됨
- 사용자 승인을 받고 새 `profit_engine_version`으로 고정됨

성과 개선과 안전성 개선이 충돌하면 실계좌에서는 안전성을 우선하고 개선판은 모의 환경에서 추가 검증한다.
